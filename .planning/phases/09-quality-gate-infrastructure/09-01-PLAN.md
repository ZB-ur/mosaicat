    ```typescript
    // Implementation status for individual code files (per D-04)

    export const QualityGateSchema = z.object({
      stub_count: z.number(),
      partial_count: z.number(),
      complete_count: z.number(),
      coverage_gaps: z.array(z.string()),  // F-NNN IDs not covered
      blocked: z.boolean(),
    });
    export type QualityGate = z.infer<typeof QualityGateSchema>;

    // AST analysis result types
    export type StubIssueType = 'empty-body' | 'return-null' | 'empty-jsx' | 'todo-fixme';

    export interface StubIssue {
      type: StubIssueType;
      line: number;
      detail: string;
    }

    export interface FileAnalysis {
      filePath: string;
      issues: StubIssue[];
      status: ImplementationStatus;
      functionCount: number;
      stubFunctionCount: number;
      hasTodoFixme: boolean;
    }
    ```

  <action>
    **Create `src/core/hooks/ast-quality-gate.ts`** implementing the AST stub detection hook per D-01, D-02, D-04, D-06.

    Use TypeScript compiler API (`import ts from 'typescript'`) with `ts.createSourceFile()` for single-file AST parsing. Per Pitfall 1, set ScriptKind based on file extension: `.tsx/.jsx` -> `ts.ScriptKind.TSX`, `.ts/.js` -> `ts.ScriptKind.TS`.

    **Exported functions:**

    1. `analyzeFile(filePath: string, content: string): FileAnalysis` -- Parse file into AST, walk tree to detect:
       - Empty function/method/arrow bodies: `ts.isFunctionDeclaration || ts.isMethodDeclaration || ts.isArrowFunction || ts.isFunctionExpression` where `node.body` is a Block with 0 statements -> issue `'empty-body'`
       - Return null/undefined only: Block body with exactly 1 statement that is `ts.isReturnStatement` where expression is null keyword, `undefined` identifier, `void` expression, or missing (bare return) -> issue `'return-null'`
       - Empty JSX elements: `ts.isJsxElement` with `node.children.length === 0` -> issue `'empty-jsx'`
       - TODO/FIXME in string literals and template literals (NOT in comments): Walk `ts.isStringLiteral` and `ts.isNoSubstitutionTemplateLiteral` and `ts.isTemplateExpression`, check text for `/\bTODO\b|\bFIXME\b/` -> issue `'todo-fixme'`
       Per Pitfall 2: Check `ts.isBlock(node.body)` before accessing `.statements`. Arrow functions with expression bodies are inherently non-empty.
       Track total function count and stub function count.
       Use `sourceFile.getLineAndCharacterOfPosition(node.getStart(sourceFile)).line + 1` for line numbers.

    2. `classifyFile(analysis: FileAnalysis): ImplementationStatus` -- Per D-04:
       - `'stub'`: stubFunctionCount > 0 AND stubFunctionCount === functionCount (all functions are stubs)
       - `'partial'`: hasTodoFixme OR (stubFunctionCount > 0 AND stubFunctionCount < functionCount)
       - `'complete'`: everything else

    3. `createAstQualityGateHook(store: ArtifactStore): PostRunHook` -- Factory function per established pattern:
       - `name: 'ast-quality-gate'`
       - `mandatory: true` (per D-06 -- all-or-nothing blocking)
       - `execute(context, _output)`: Read code files from `store.getDir() + '/code'` directory. Filter to `.ts/.tsx/.js/.jsx` extensions (per D-02). Run `analyzeFile` + `classifyFile` on each. If ANY file has status `'stub'` or `'partial'`, write `quality-gate-report.md` artifact (listing all issues per file) to store, then return `{ pass: false, message: '...' }`. Otherwise return `{ pass: true }`.
       - Use `fs.readdirSync` recursively to find code files. Use `fs.readFileSync` to read content.
       - The quality-gate-report.md follows format: `# Quality Gate Report\n\n## Stub/Partial Files\n\n- path: status (N issues)\n  - line X: issue-type: detail\n`

    **Create `src/core/__tests__/ast-quality-gate.test.ts`** with tests for all behaviors listed above. Use Vitest. For hook tests, create a temp directory with mock code files, create an ArtifactStore pointing to it, and test hook execution.
