    1. **Type `TestFailureCategory`**: `'parse-import' | 'assertion' | 'runtime'` -- the 3 categories per D-04.

    2. **Interface `ClassifiedFailure`**: `{ testName: string; category: TestFailureCategory; errorSnippet: string }`.

    3. **Interface `FailureFingerprint`**: `{ entries: string[]; hash: string }` where entries are sorted `"testName:category"` strings and hash is `entries.join('|')`.

    4. **Function `classifyTestFailure(errorText: string): TestFailureCategory`**:
       - Priority order: parse-import checked first, then assertion, then runtime (fallback).
       - parse-import regexes: `/cannot find module|module not found|err_module_not_found/i`, `/syntaxerror|unexpected token|parsing error/i`, `/ts\d{4}:|cannot find name|is not assignable/i`, `/cannot resolve|failed to resolve import/i`.
       - assertion regexes: `/expect\(|assertion|tobe|toequal|tohave|assert\./i`, `/expected.*received|expected.*but got/i`.
       - Everything else: `'runtime'`.

    5. **Function `classifyTestOutput(vitestOutput: string): ClassifiedFailure[]`**:
       - Parse vitest output for FAIL blocks. Pattern: `/FAIL\s+(.+?)(?:\n|$)/g` for test file names, then look for error text after each FAIL line (next ~10 lines or until next FAIL/empty line).
       - For each failure, call `classifyTestFailure()` on the error text.
       - Return array of `ClassifiedFailure` objects.

    6. **Function `createFingerprint(failures: ClassifiedFailure[]): FailureFingerprint`**:
       - Map each failure to `"testName:category"`, sort alphabetically, join with `'|'` for hash.

    7. **Function `fingerprintsMatch(a: FailureFingerprint, b: FailureFingerprint): boolean`**:
       - Compare `a.hash === b.hash`.

    8. **Function `getDominantCategory(failures: ClassifiedFailure[]): TestFailureCategory`**:
       - Count occurrences of each category. Return the most frequent.
       - Tie-breaking priority: `parse-import` > `assertion` > `runtime` (per D-05, parse/import errors should be fixed first).
       - Empty array returns `'runtime'`.

    This module is NEW and separate from `retry-log.ts`. The existing `classifyError()` in retry-log.ts is NOT modified -- it has 8+ categories for general retry logging. This module has the coarser 3-category classification specifically for fix-loop strategy routing per D-04.

       private runPreCompilation(codeDir: string): { success: boolean; errors: string } {
         const testDir = path.join(codeDir, 'tests', 'acceptance');
         if (!fs.existsSync(testDir)) {
           // No test directory -- skip pre-compilation, let vitest handle it
           return { success: true, errors: '' };
         }

         // Check for tsconfig.json in codeDir
         const hasTsconfig = fs.existsSync(path.join(codeDir, 'tsconfig.json'));
         const cmd = hasTsconfig
           ? 'npx tsc --noEmit'
           : 'npx tsc --noEmit tests/acceptance/**/*.ts --esModuleInterop --moduleResolution node';

         try {
           execSync(cmd, { cwd: codeDir, timeout: 60_000, stdio: 'pipe', encoding: 'utf-8' });
           return { success: true, errors: '' };
         } catch (err: unknown) {
           const error = err as { stdout?: string; stderr?: string; message?: string };
           const output = `${error.stdout ?? ''}\n${error.stderr ?? ''}`.trim();
           return { success: false, errors: output || error.message || 'Unknown tsc error' };
         }
       }
       ```

    2. **Add `import path from 'node:path'`** at the top of the file (fs is already imported).

    3. **Modify `run()` method** -- insert pre-compilation step AFTER setup but BEFORE runTests():

       // Step 1.5: Pre-compilation check (D-07, D-08)
       this.ctx.eventBus.emit('agent:progress', this.stage, 'pre-compiling test files (tsc --noEmit)');
       const preCompile = this.runPreCompilation(codeDir);
       if (!preCompile.success) {
         this.logger.agent(this.stage, 'warn', 'tester:precompile-failed', {
           errors: preCompile.errors.slice(0, 1000),
         });
         this.ctx.eventBus.emit('agent:progress', this.stage, 'pre-compilation failed — skipping vitest');

         // Per D-08: skip vitest, report as parse-import failure
         this.generatePreCompileFailureReport(preCompile.errors);
         this.ctx.eventBus.emit('agent:summary', this.stage, 'Pre-compilation failed — vitest skipped');
         return;
       }
       this.logger.agent(this.stage, 'info', 'tester:precompile-passed', {});
       ```
